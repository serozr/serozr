### [DNSVet](https://github.com/serozr/dnsvet)

An open-source DNS diagnostics and intelligence toolkit written in Go.

- Cross-platform command-line tool targeting Windows, Linux, and macOS.
- Focuses on resolver behavior, DNS diagnostics, performance, privacy, and security indicators.
- Includes DNSSEC validation primitives and structured JSON output.
- Designed around explicit, testable rules and local-first operation.

<sub>Status: Early development. Check the repository README for implemented capabilities and current limitations.</sub>

### [Cyber Portfolio](https://github.com/serozr/cyber-portfolio)

A terminal-inspired personal portfolio website built with vanilla web technologies.

- Responsive interface with a cyber-inspired visual identity.
- Terminal boot animation and interactive UI details.
- Built with HTML, CSS, and vanilla JavaScript.
- Designed to present projects, skills, and development work.
